
# ShoppingCart TypeScript Task

This project demonstrates the implementation of a simple shopping cart using TypeScript. The cart can store items, calculate the total price, and manage the items by adding or removing them.

## Features

- Add items to the cart
- Remove items from the cart
- Calculate the total price of all items
- Strictly typed methods and properties with TypeScript

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/seifsheikhelarab/shopping-cart-typescript.git
   cd shopping-cart-typescript
   ```

2. Install dependencies (if any):
   ```bash
   npm install
   ```

3. Compile and run the TypeScript code:
   ```bash
   tsc index.ts
   node index.js
   ```

## Code Overview

- `Item` Interface: Defines the structure of an item in the cart.
- `ShoppingCart` Class: Contains methods to add items, remove items, and calculate the total price.
